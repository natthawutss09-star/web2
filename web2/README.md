# คลังหนังสือบาลี

เว็บ HTML + เซิร์ฟเวอร์ Node.js ตัวเล็ก (ไม่ต้องติดตั้งแพ็กเกจเพิ่ม) หน้าบ้านกับหลังบ้านใช้ข้อมูลชุดเดียวกัน
คือไฟล์ `data/books.json` — หลังบ้านเพิ่ม/แก้/ลบ/อัปโหลดแล้ว ผู้เข้าชมเห็นทันที

## วิธีรัน (แนะนำ)
1. ติดตั้ง Node.js 18 ขึ้นไป
2. เปิดเทอร์มินัลในโฟลเดอร์นี้ แล้วรัน `node server.js`
3. เปิด http://localhost:3000 (หน้าเว็บ) และ http://localhost:3000/admin/login.html (หลังบ้าน)

ตั้งรหัสผ่านจริงก่อนใช้งานจริง:

```
ADMIN_USER=ชื่อผู้ใช้ ADMIN_PASS=รหัสผ่าน node server.js
```

ตัวเลือกอื่น: `PORT=8080` เปลี่ยนพอร์ต, `MAX_UPLOAD_MB=300` เปลี่ยนขนาดไฟล์อัปโหลดสูงสุด (ค่าเริ่มต้น 200)
ค่าเริ่มต้นคือ `admin` / `123456789` — เหมาะกับทดลองในเครื่องเท่านั้น

## โครงสร้าง
- หน้าบ้าน: index.html, books.html, about.html, contact.html
- หลังบ้าน: admin/login.html → admin/dashboard.html
- **data/books.json** — รายการหนังสือ (ศูนย์กลางข้อมูล)
- **books/** — ไฟล์ PDF (อัปโหลดจากหลังบ้านจะลงที่นี่เอง)
- server.js — เสิร์ฟหน้าเว็บ + API (`/api/login`, `/api/books`, `/api/upload`)
- css/style.css, js/common.js (ฟังก์ชันร่วม + ค่าเริ่มต้นสำรอง `defaultBooks()`)

## ทำงานอย่างไร
- หน้าบ้านโหลดรายการจาก `data/books.json` ทุกครั้งที่เปิดหน้า
- หลังบ้านล็อกอินผ่านเซิร์ฟเวอร์ (ได้ token) แล้วบันทึกรายการกลับไปที่ `data/books.json`
- อัปโหลด PDF: เลือกไฟล์ในแบบฟอร์ม ระบบเก็บลง `books/` แล้วเติมพาธกับขนาดไฟล์ให้ จากนั้นกด "บันทึก"
- ลบหนังสือในหลังบ้านจะลบเฉพาะรายการ ไม่ลบไฟล์ PDF ใน `books/`
- ลิงก์ภายนอก (MediaFire / Google Drive) ใส่ในช่อง "ลิงก์/พาธไฟล์" ได้เหมือนเดิม

## โหมดไม่มีเซิร์ฟเวอร์ (โฮสต์ไฟล์ธรรมดา เช่น Netlify, GitHub Pages, Live Server)
ใช้ได้ แต่หน้าบ้านกับหลังบ้านจะไม่เชื่อมกันอัตโนมัติ
- หลังบ้านบันทึกเป็นร่างในเบราว์เซอร์ของแอดมินเท่านั้น (ขึ้นแถบเตือนสีส้ม) และอัปโหลดไฟล์ไม่ได้
- ถ้าจะให้ผู้เข้าชมเห็นการแก้ไข: กด "สำรองข้อมูล (books.json)" แล้วนำไฟล์ไปวางทับ `data/books.json` และอัปโหลดเว็บใหม่
- ล็อกอินตรวจฝั่งเบราว์เซอร์ด้วยรหัสใน admin/login.html ซึ่งไม่ปลอดภัยจริง

## นำขึ้นออนไลน์ให้เชื่อมกันจริง
ต้องใช้โฮสต์ที่รัน Node.js ได้ (VPS, Render, Railway ฯลฯ) ตั้งคำสั่งเริ่มเป็น `node server.js`
แล้วกำหนดค่า `ADMIN_PASS` ในหน้าตั้งค่าของโฮสต์ ข้อควรระวัง: โฮสต์ฟรีบางเจ้าล้างดิสก์ทุกครั้งที่รีสตาร์ต
ต้องผูกพื้นที่เก็บถาวร (persistent disk) กับโฟลเดอร์ `data/` และ `books/` ไม่เช่นนั้นข้อมูลและไฟล์ที่อัปโหลดจะหาย

## ความปลอดภัย
- ฝั่งเซิร์ฟเวอร์ตรวจรหัสผ่านจริง ผิด 5 ครั้งถูกพัก 5 นาที เขียนข้อมูล/อัปโหลดได้เฉพาะผู้ที่ล็อกอิน
- รับอัปโหลดเฉพาะไฟล์ที่ขึ้นต้นเป็น PDF และไม่เขียนทับไฟล์ชื่อเดิม
- ใช้ HTTP ธรรมดา ถ้านำขึ้นอินเทอร์เน็ตควรวางหลัง HTTPS (โฮสต์ส่วนใหญ่ทำให้อยู่แล้ว)
